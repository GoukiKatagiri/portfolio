# ポートフォリオ

小規模な自動化ツールと Web ページ制作のサンプルです。いずれも架空のデータで作っています。

| サンプル | 内容 | 技術 |
|---|---|---|
| [売上明細の担当者別・月別集計](gas-sales-summary/) | スプレッドシートのメニューから、担当者 × 月の集計表を作る | Google Apps Script |
| [顧客リスト × 注文リスト CSV 突合](python-csv-reconcile/) | 文字コードや表記ゆれを吸収して 2 つの CSV を紐づけ、未一致を書き出す | Python |
| [音楽教室のランディングページ](lp-music-school/) | スマホ対応の 1 ページ LP（[表示を見る](https://goukikatagiri.github.io/portfolio/lp-music-school/)） | HTML / CSS |

各フォルダの README に、できること・使い方・テスト方法を書いています。

制作には AI コーディング支援ツール（Claude Code）を使用し、動作確認は私が行っています。
