# 売上明細 → 担当者別・月別集計（Google Apps Script）

スプレッドシートに溜まった売上明細から、担当者 × 月の集計表をボタン 1 つで作るスクリプトです。毎月の手作業のピボット集計をなくします。

## できること
- メニュー「集計 > 月別集計を更新」で、「月別集計」シートに集計表を作り直します
- 合計行・合計列を付け、金額は 3 桁区切りで表示します
- 日付は `2026/9/3` と `2026-09-03` のどちらの書き方でも、日付型のセルでも読めます
- 担当者が空欄、数量が数字でない、などの行は集計から外し、何行目かを画面右下に通知します

## 導入手順
1. Google スプレッドシートを新規作成し、画面左下のタブ「シート1」をダブルクリックして「売上」に変える（ファイル名ではなく、タブの名前です）
2. 「ファイル > インポート」で `sample-data.csv` を読み込む（「現在のシートを置換」を選ぶ）
3. 「拡張機能 > Apps Script」を開き、`Code.gs` の中身を貼り付けて保存する
   - 「現在、ファイルを開くことができません」と表示される場合は、ブラウザで複数の Google アカウントにログインしていることが原因です。スプレッドシートを作ったアカウントだけでログインしたウィンドウ（シークレットウィンドウなど）で開き直してください
4. スプレッドシートを再読み込みすると、メニューに「集計」が出る
5. 「集計 > 月別集計を更新」を実行する。初回だけ Google の承認画面が出る

| 高橋 | 0 | 6,600 | 9,600 | 16,200 |
| 佐藤 | 20,550 | 21,150 | 0 | 41,700 |
| 田中 | 21,600 | 8,750 | 12,150 | 42,500 |
| 鈴木 | 30,700 | 600 | 25,750 | 57,050 |
| 合計 | 72,850 | 37,100 | 47,500 | 157,450 |

サンプルデータは架空のものです。

## テスト
集計の計算部分はシートから切り離した関数にしてあり、Node.js で確認できます。

```bash
node test.js
```

## カスタマイズの例
集計の軸（商品別・週別など）、毎朝の自動実行（トリガー）、集計結果の Slack・メール通知、複数シートや別ファイルからの取り込みなどに対応できます。
