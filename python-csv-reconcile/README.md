# 顧客リスト × 注文リスト CSV 突合ツール

別々のシステムから書き出した顧客リストと注文リストを、メールアドレスや電話番号で紐づけるツールです。手作業の VLOOKUP では拾えない表記ゆれを吸収します。

## できること
- 文字コードの自動判別: Excel で保存した CSV（Shift_JIS）と UTF-8 の CSV が混ざっていても読めます
- 表記ゆれの吸収: 全角/半角、余分な空白、電話番号のハイフンや括弧、メールアドレスの大文字/小文字を揃えてから照合します
- 照合の優先順位: メールアドレスで一致しなければ電話番号で照合します。どちらで紐づいたかを結果に残します
- 未一致の書き出し: 紐づかなかった注文を別ファイルに出すので、確認すべき行がすぐ分かります
- Excel でそのまま開ける形式（UTF-8 BOM 付き）で出力します

## 使い方
Python 3.9 以降が入っていれば、追加のインストールは不要です。

```bash
python reconcile.py sample/customers.csv sample/orders.csv -o out
```

```
注文 7 件 / 紐づけ 5 件 / 未一致 2 件
```

`out/matched.csv`（紐づいた注文）と `out/unmatched.csv`（紐づかなかった注文）ができます。

## 同梱サンプル
`sample/` のデータはすべて架空のものです。顧客リストは Shift_JIS、注文リストは UTF-8 で、全角の電話番号や大文字のメールアドレスなど、実務でよくある表記ゆれを含めています。

## テスト
```bash
python -m unittest -v test_reconcile
```

## カスタマイズの例
列名・照合キー・出力項目は案件ごとに合わせられます。氏名とふりがなでのあいまい照合、複数ファイルの一括処理、Google スプレッドシートへの書き出しなども対応できます。
