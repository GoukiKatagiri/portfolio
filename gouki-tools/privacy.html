Gouki Tools プライバシーポリシー

制定日: 2026年10月4日

Gouki Tools（以下「本ツール」）は、片桐豪生（以下「開発者」）が自分の作業のためだけに使う個人用のツールです。開発者以外の利用者はいません。

1. 取得する情報

本ツールは、開発者本人の Google アカウントについて、次の情報にアクセスします。

  • Gmail（読み取り専用）: メールの差出人・件名・本文
  • Google カレンダー: 予定の照会と登録

2. 利用目的

クラウドソーシングの案件や取引相手からの連絡に関するメールを選び出し、その要点を開発者本人に知らせるため、および開発者本人の予定を管理するためにのみ利用します。

3. 処理と保存

  • メールの内容は、開発者本人のパソコン上で処理します。要約と判定のために、AI サービス（Anthropic 社の Claude）に送信することがあります
  • 要約した結果は、メッセージアプリ（Telegram）で開発者本人だけに送ります
  • 開発者のパソコンには、処理済みのメールの識別番号と動作記録だけを保存します。メール本文は保存しません

4. 第三者への提供

取得した情報を、上記 3 の処理に必要な範囲を除いて第三者に提供・販売することはありません。広告には利用しません。

5. Google API から取得したデータの扱い

本ツールによる Google API から取得した情報の利用と他のアプリへの転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

6. アクセスの取り消し

本ツールのアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. 連絡先

GitHub のプロフィール（GoukiKatagiri）からご連絡ください。
