# 音楽教室のランディングページ（架空）

大人向け音楽教室を想定した 1 ページの LP です。教室名・料金・文章はすべて架空です。

## 構成
ヒーロー（キャッチコピーと予約ボタン）/ 選ばれる理由 / コース・料金 / よくある質問 / 予約への誘導

## 実装のポイント
- HTML と CSS のみ。ライブラリや画像に依存しないので軽く、そのままどのサーバーにも置けます
- スマホ・タブレット・PC の 3 段階でレイアウトを切り替えます（幅 375px で横スクロールが出ないことを確認済み）
- 見出しが文節の途中で改行されないよう調整しています
- ヘッダーは画面上部に固定し、ページ内リンクで移動したときに見出しがヘッダーに隠れないようにしています
- よくある質問は `details` 要素の開閉で、JavaScript を使っていません
- 色や角丸は CSS 変数にまとめてあり、ブランドカラーの差し替えが 1 箇所で済みます

## 表示方法
`index.html` をブラウザで開いてください。

## カスタマイズの例
デザインカンプ（Figma・XD・画像）からのコーディング、予約フォームの設置（Google フォーム連携など）、既存サイトのスマホ対応にも対応できます。
